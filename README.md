# Last Train to Dawn

《开往黎明的末班车》是一款由 AlterU Cinematic Civic 叙事框架驱动的状态型角色扮演游戏。

玩家临时接管洪灾地区最后一列还能运行的柴油列车，在八章旅程中选择路线、维修列车、管理燃料、招募伙伴、处理危险，并决定列车抵达黎明枢纽后的归属。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目文档位于 `doc/requirements.md`、`doc/visual.md` 与 `doc/technical.md`。
